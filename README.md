## Requirements

- Python 3.x
- Flask

## Installation

```bash
pip install Flask
```

## Usage

```bash
python3 server.py
``` 

The app will be available at: http://127.0.0.1:5001

## Project Structure

- `server.py`: Flask application
- `templates/`: HTML templates
- `static/`: CSS and JavaScript assets
